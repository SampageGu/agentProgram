# MiniCode M5 多 Agent 验收指南

## M5.1：独立 Explore Subagent

本节单独验收 Explore child 本身；主 CodingAgent 的自动调用由后面的 M5.2 验收。

### 自动验收

```powershell
.\start.cmd test
```

通过标准：显示 `Ran 34 tests` 和 `OK`。其中 M5.1 用例必须证明：

- child 只能看到 `list_files`、`search_code`、`read_file`；
- child 有独立步骤预算并能以 `budget_exhausted` 停止；
- child 达到 64K Token 硬预算时在执行更多工具前停止；
- 报告字段、路径和行号经过确定性校验；
- `.env` 等受保护证据会被拒绝；
- child Trace 包含 `subagent_started` 与 `subagent_completed/failed`；
- 报告保存 parent/child Run ID。

### 真实 DeepSeek 验收

确保根目录 `.env` 已填写 API Key，然后运行：

```powershell
.\start.cmd explore "定位 M4 Web 服务的入口、HTTP 路由和安全边界，请给出代码证据"
```

成功标准：

1. 首先显示 Explore Subagent 启动；
2. 至少调用一个只读工具，通常会搜索并读取 `web.py`；
3. 不出现 `apply_patch`、`run_command`、`run_tests` 或委派工具；
4. 最终状态为 `completed`；
5. 输出 Child Run ID、Trace 和 Report 路径；
6. `exploration-report.json` 包含 summary、evidence、root cause、next steps、risks；
7. 每条 evidence 都是存在的相对路径与真实行号；
8. Trace 首尾包含 Subagent 事件，且不包含 API Key。

可查看 child 时间线：

```powershell
.\start.cmd replay <child_run_id>
```

### 当前边界

- 这是独立 Explore Subagent，还不是主 Agent 自动委派；
- parent Run ID 协议进入报告和 child Trace；父 Trace 关联由 M5.2 覆盖；
- 每个 child 最多 8 步，默认 8 步；Prompt 要求通常在 4 轮内完成，并在最后可用轮次停止取证；
- 不支持递归 Subagent；
- 报告校验能过滤格式和证据错误，但不能保证模型推断一定正确，主 Agent 后续仍需复核关键文件。

## M5.2：主 Agent 委派

### 自动验收

```powershell
.\start.cmd test
```

当前应显示 `Ran 37 tests` 和 `OK`。M5.2 专项测试必须证明：

- parent 调用 `delegate_explore` 后产生独立 child Trace；
- child 报告只以结构化工具结果进入 parent 上下文；
- parent 未重新读取 child 证据文件时，`apply_patch` 返回 `subagent_evidence_unverified`；
- 父端复核后可以 Patch、测试、Diff 并完成；
- 第三次委派被 `delegation_limit` 拒绝；
- child 非法报告不会卡死 parent，直接 search/read 仍可用；
- 委派与复核状态序列化后保持一致。

### 真实模型验收

```powershell
.\start.cmd demo
```

成功标准：

1. parent 首先出现 `[委派]`，随后产生 child Run ID；
2. child 只能调用 list/search/read，最终返回结构化报告；
3. parent Trace 出现 `subagent_delegated` 和 `subagent_result`；
4. parent 在 `apply_patch` 前再次读取至少一个 child 引用文件；
5. 最终测试通过、Diff 已查看、完成协议通过；
6. Demo workspace 中同时存在 parent 与 child 的 `.mini-code/runs/<run_id>/events.jsonl`；
7. 若 child 达到 6 步或 32K Token 预算，parent 应报告 child 失败并使用自己的只读工具继续，而不是整个任务崩溃。

为了做单 Agent 对照，可对同一测试 workspace 使用：

```powershell
.\.venv\Scripts\python.exe run_mini_code.py run `
  "修复除零 Bug，运行测试并查看 Diff" `
  --workspace D:\path\to\test-repo --env-file .env --no-subagents
```

M5.2 通过后仍不能宣称 Web 已展示多 Agent。父子 Replay 聚合和 Web Subagent 卡片属于 M5.3。
