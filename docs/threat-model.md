# M3 威胁模型

## 保护目标

- 不让模型工具读取工作区外、`.env`、`.git` 和 `.mini-code`；
- 不让模型绕过命令白名单启动 Shell、网络工具、任意 Python 或 Git 写操作；
- 不让 unified diff 删除、重命名、修改受保护路径或越过工作区；
- 不把宿主环境中的 Key、Token、Secret、Password 传给测试子进程；
- 恢复前检测用户或其他进程对工作区的外部修改。

## 已实现控制

路径解析与保护目录校验、参数数组启动且 `shell=False`、命令与 Python 模块白名单、环境变量过滤、Patch 预校验、步骤/输出/超时预算、测试和 Diff 后才能完成、checkpoint 指纹冲突检测。`security-check` 固定执行 15 个路径、秘密文件、Shell、网络、Git 写入和未知工具探针。

## 明确不在当前安全边界内

仓库自己的测试代码会以当前操作系统用户权限运行；Python 依赖、测试或编译脚本可能读写其他文件或访问网络。M3 没有容器、虚拟机、系统调用过滤、网络隔离和人工审批队列。因此“15/15 探针通过”只代表当前版本化策略用例被阻断，不代表任意恶意仓库都安全。只应在可信仓库或额外 OS 沙箱中运行。

Trace、checkpoint 和 artifact 可能保存私有源码。API Key 不应写进任务文本或仓库文件，只放在被保护且被 Git 忽略的 `.env`。
