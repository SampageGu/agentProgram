# M3 评测说明

`evals/tasks/m3.json` 固定了 20 个小型 Python 修复任务，覆盖数学、边界、递归、规范化、集合、解析、逻辑和映射 8 类问题。每题满足：公开测试初始通过，工作区外的隐藏测试初始失败。

运行真实评测：

```powershell
.\start.cmd eval3 20
```

报告写入 `.mini-code/evals/m3-<suite_id>/report.json`，包含任务成功率、公开测试通过率、回归率、无关修改率、平均步骤、P50/P95 耗时、Token 覆盖和估算成本。成本只有在 `.env` 配置两个价格快照且 API 返回 usage 时才计算；价格不硬编码，以免过期。

这组任务适合验证 Agent Loop 和做版本间回归比较，但不能代表真实大型仓库表现。已知弱点包括：任务均为 Python 小函数、依赖少、上下文短，尚未覆盖跨语言构建、复杂依赖、长时间命令和大型重构。
